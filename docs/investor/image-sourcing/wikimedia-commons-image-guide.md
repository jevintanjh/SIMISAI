## DOWNLOAD WORKFLOW

### For Each Image:

1. **Click the search URL** provided above
2. **Browse results** (usually see 20-50 images)
3. **Select best match** based on criteria
4. **Click image** to view full size
5. **Check resolution**: Should be 1920x1080 minimum (shown in image details)
6. **Click "Use this file"** button (right side of page)
7. **Select "Original"** or "Large" size
8. **Right-click on image** → "Save Image As"
9. **Rename immediately** to correct filename
10. **Document attribution** (shown on Wikimedia page):
    - Photographer name
    - License type (usually CC BY-SA or CC0)
    - Source organization (if applicable)

### License Types on Wikimedia (All Free to Use):

- **CC0 (Public Domain)**: No attribution required, completely free
- **CC BY**: Attribution required (credit photographer)
- **CC BY-SA**: Attribution + share-alike (if you modify, same license)
- All three are **free for commercial use** including conference presentations

### Attribution Template:

Save this info for each image:
```
Image: [filename]
Source: Wikimedia Commons
Photographer: [name from image page]
License: [CC0 / CC BY / CC BY-SA]
URL: [image page URL]
```

## TROUBLESHOOTING

### Issue: "Not finding enough Asian subjects"

**Solution**:
- Add country names to search: "philippines", "indonesia", "thailand", "vietnam"
- Search WHO/Red Cross categories on Wikimedia Commons
- Broaden to "Asian" instead of "Southeast Asian"
- Search by city: "manila", "bangkok", "jakarta", "singapore"

### Issue: "Images too low resolution"

**Solution**:
- Always download "Original" size, not thumbnails
- Look for images from professional NGOs (WHO, Red Cross, medical schools)
- Check "File history" section for higher resolution versions
- Some images have multiple resolutions - select largest

### Issue: "Medical devices not visible in elderly images"

**Solution**:
- Search separately: "blood pressure monitor device" (find device image)
- Combine elderly portrait + device image on slide using image editing
- Acceptable compromise: Elderly in healthcare context without visible device
- Search "home healthcare" or "telemedicine" for combined images

### Issue: "Can't tell what license image has"

**Solution**:
- License info is on RIGHT side of image page under "Licensing"
- If license is unclear, look for "Public domain" or "CC0" (safest)
- All Wikimedia Commons images are free to use - just check if attribution needed
- When in doubt, copy the attribution info anyway

## WHY THIS WORKS BETTER THAN UNSPLASH/PEXELS

**Wikimedia Commons Advantages:**

1. **Documentary Photography**: Real healthcare situations (not staged stock)
2. **NGO Archives**: WHO, Red Cross, medical schools contribute authentic images
3. **Regional Coverage**: Strong Southeast Asian content from regional photographers
4. **Free Forever**: Images won't be removed or paywalled
5. **High Resolution**: Many images 3000x2000+
6. **Proper Context**: Images often from actual healthcare programs
7. **Cultural Authenticity**: Less "tokenistic" than staged stock photos

**Compared to Unsplash/Pexels:**
- More authentic medical device contexts
- Better Southeast Asian representation
- Higher likelihood of documentary-style (not posed)
- Images from actual healthcare organizations
- Proper licensing documentation
- Images don't expire or get removed
