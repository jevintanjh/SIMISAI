## 🔧 TECHNICAL SPECIFICATIONS

### Minimum Requirements
- **Resolution**: 1920x1080 (Full HD)
- **Preferred Resolution**: 3000x2000 or higher (Unsplash originals typically deliver this)
- **Format**: JPG (PNG also acceptable, but JPG is standard)
- **File Size**: 500KB - 5MB (optimal for presentation)
- **Color Space**: sRGB (standard for digital presentations)
- **Orientation**: Landscape (except Image 5 - portrait OK for testimonial)

### How to Check Resolution (After Download)
**Mac**: Right-click image → Get Info → More Info section → Dimensions
**Windows**: Right-click image → Properties → Details tab → Dimensions
**Should see**: 3000 x 2000 or similar (Unsplash originals)

## ⚠️ TROUBLESHOOTING

### Issue: "Image resolution too low after download"
**Solution**: Ensure you clicked "Original" size, not "Large" or "Medium". Original on Unsplash is always 3000x2000+.

### Issue: "Can't find image on Unsplash (404 error)"
**Solution**:
1. Photo may have been removed by photographer
2. Use alternative search terms provided
3. Search Pexels as backup using same keywords

### Issue: "Image doesn't match Southeast Asian requirement"
**Solution**:
1. These images were pre-vetted for Asian subjects
2. If needed, use broader "Asian" search (Chinese, Japanese, Korean acceptable)
3. Prioritize authentic emotion and dignity over perfect ethnicity match

### Issue: "Downloaded image has watermark"
**Solution**:
- Unsplash images are watermark-free
- If you see watermark, you may have saved preview/thumbnail instead of downloading via button
- Re-download using "Download free" button

### Issue: "Image feels too 'stock photo'"
**Solution**:
- Unsplash generally has more authentic images than traditional stock sites
- If image feels staged, use alternative search terms for "candid", "authentic", "documentary"
- Prioritize images with natural lighting and real-world settings
