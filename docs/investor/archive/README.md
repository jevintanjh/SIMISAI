**Question**: "Why did you switch from bulk prompts to slide-by-slide?"

   - Bulk prompts: Fast but less control
   - Slide-by-slide: Slower but higher quality
   - Decision: Quality > Speed for investor pitches

## 💡 Archive Management Guidelines

### **What Belongs in Archive**

✅ Completed research that informed current materials
✅ Historical versions replaced by better ones
✅ Background documents no longer actively used
✅ Deprecated tools and scripts
✅ Analysis that led to implemented changes

### **What Should NOT Be Archived**

❌ Active working documents
❌ Current presentation materials
❌ Frequently referenced resources
❌ Tools and automation scripts in use
❌ Live strategy and planning documents
