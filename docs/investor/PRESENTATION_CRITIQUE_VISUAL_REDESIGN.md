## 🎨 VISUAL DESIGN BEST PRACTICES

### Text Reduction Guidelines (SIMISAI-Specific)

1. **Eliminate Redundancy**:
   - ❌ "Our platform uses advanced AI and machine learning technology to help elderly users..."
   - ✅ "AI-powered guidance for elderly users"

2. **Use Power Words Only**:
   - Keep: "Revolutionary", "First", "Proven", "76M", "$12B", "92% accuracy"
   - Cut: Connective phrases, explanatory clauses, adjective stacking

3. **Icon Substitution**:
   - Replace bullet points with meaningful icons
   - Replace feature lists with visual checkmarks
   - Replace data with charts/graphs

4. **Headline + Subheadline Formula**:
   - Headline: 3-6 words (impact statement)
   - Subheadline: 10-15 words (key detail)
   - Body: 15-25 words maximum (if absolutely needed)

5. **40-Word Rule Per Slide**:
   - Title: 5-8 words
   - Main content: 20-30 words
   - Supporting text: 5-10 words
   - Total: ≤40-50 words

### Visual Hierarchy Best Practices

1. **The 60-30-10 Rule**:
   - 60% visual content (images, diagrams, charts)
   - 30% whitespace (breathing room)
   - 10% text (minimal, high-impact)

2. **F-Pattern Reading**:
   - Place most important visual top-left
   - Place supporting visuals middle-center
   - Place CTA/takeaway bottom-right

3. **Z-Pattern for Action Slides** (Slides 9-10):
   - Top-left: Key metric/visual
   - Top-right: Supporting data
   - Bottom-left: Secondary info
   - Bottom-right: Call to action

### Image Placement Guidelines

1. **Hero Images** (Slides 1, 10):
   - Full-bleed or 60-70% coverage
   - Text overlay with gradient/darkening
   - Emotional, high-quality, culturally relevant

2. **Supporting Images** (Slides 2-8):
   - 40-50% of slide real estate
   - Complement but don't compete with data visuals
   - Always have purpose (not decoration)

3. **Image Quality Standards**:
   - Minimum resolution: 1920x1080 (Full HD)
   - No watermarks
   - No AI-generated images (per user preference)
   - Culturally authentic (Southeast Asian subjects)

### Chart & Diagram Specifications

1. **Data Visualization Rules**:
   - **Maximum 3-4 data points** per chart
   - **No gridlines** unless essential
   - **Large fonts** (18pt minimum for labels)
   - **High contrast colors** (avoid pastels)
   - **Legends as direct labels** (not separate legends)

2. **Icon Set Consistency**:
   - Use ONE icon set throughout (e.g., Font Awesome, Heroicons)
   - Consistent stroke weight
   - Consistent color palette
   - Size: 48-64px for primary icons

3. **Infographic Design**:
   - Start with template (Canva, Venngage)
   - Limit to 3 colors + black/white
   - Use size to indicate importance
   - Include whitespace between elements

### Color Psychology for Medical/Health Pitch

1. **Primary Palette**:
   - **Teal/Turquoise** (#00A896): Trust, healthcare, technology
   - **Navy Blue** (#002147): Professionalism, stability
   - **Warm Orange** (#FF6B35): Energy, innovation, accessibility

2. **Accent Colors**:
   - **Green** (#00C851): Success, validation, growth (for checkmarks, positive metrics)
   - **Red** (#CC0000): Urgency, problem statements (use sparingly)

3. **Avoid**:
   - All-gray slides (looks medical but cold)
   - Bright neon colors (unprofessional)
   - More than 4 colors per slide

### Typography Best Practices

1. **Font Hierarchy**:
   - Titles: **Sans-serif bold** (Montserrat, Inter, Poppins) - 36-48pt
   - Body: **Sans-serif regular** - 18-24pt
   - Captions: **Sans-serif light** - 14-16pt

2. **Readability Rules**:
   - Minimum font size: 18pt (must be readable from 10 feet)
   - Line height: 1.5x font size
   - Contrast ratio: 4.5:1 minimum (WCAG AA standard)

3. **Text on Images**:
   - Always use dark gradient overlay (40-60% opacity)
   - OR: Add subtle drop shadow to text
   - Ensure text color contrasts with image (white on dark, dark on light)

## 🎯 FINAL RECOMMENDATIONS

### Immediate Next Steps (This Week)

1. **Export current Gamma.app slides as editable format** (PowerPoint or Google Slides)
   - Gamma.app allows export to PPTX
   - This gives you full control for redesign

2. **Start with Top 3 slides redesign** (Slides 2, 3, 9 from examples above)
   - These have highest ROI for visual transformation
   - Will dramatically improve pitch flow

3. **Source high-priority images TODAY** (see Priority table)
   - Spend 2-3 hours on Unsplash/Pexels
   - Download 1920x1080 minimum resolution
   - Organize in folder: `/images/slide-01/`, `/images/slide-02/`, etc.

4. **Request official logos/badges** (AI Singapore, AWS)
   - Email partnerships asking for high-res logo assets
   - Mention it's for investor presentation
   - Usually granted within 48 hours

### Design Tools Recommendation

For non-designers, use:
- **Canva Pro** (best for infographics, charts, quick edits) - $12.99/month
- **Figma** (free tier sufficient for diagrams, maps)
- **Remove.bg** (remove image backgrounds) - Free
- **Unsplash + Pexels** (free stock photos)

### Testing Your Redesign

Before finalizing:
1. **10-Foot Test**: Print slide and view from 10 feet away
   - Can you read text?
   - Can you understand the visual in 5 seconds?

2. **5-Second Rule**: Show each slide for only 5 seconds
   - What's the ONE thing you remember?
   - If answer is "nothing clear", redesign needed

3. **Non-Expert Review**: Show to someone unfamiliar with SIMISAI
   - Can they explain the problem, solution, and ask after viewing?
   - If not, visuals aren't clear enough

### Pitch Delivery with New Visual Deck

Remember:
- **You are the narrator, slides are the illustration**
- Reduced text means YOU provide context verbally
- Practice timing: Each slide = 40-50 seconds max
- Don't read slides (they have minimal text now)
- Use slides as visual anchors for your talking points

### Appendix Slides Strategy

Create 5-7 backup slides with details:
- Detailed financial model
- Technical architecture deep-dive
- Team backgrounds with photos
- Competitive analysis matrix
- Customer acquisition strategy
- Regulatory/compliance details

These are NOT shown during pitch but available for Q&A.
