**Document Purpose**: Step-by-step guide to securing and executing pilots with small-medium logistics companies in Singapore
**Target**: SME 3PLs, freight forwarders, e-commerce fulfillment centers (10-100 employees)

## Why Start with SMEs?

### Advantages of SME Pilots vs Enterprise:

✅ **Fast Decision-Making**: Owner/founder decides (days/weeks vs months)
✅ **Lower Risk**: Smaller scope = less downtime risk if issues occur
✅ **Flexible**: Willing to try new technology, less bureaucracy
✅ **Grateful**: Appreciate affordable innovation (can't afford S$2.5M automation)
✅ **Case Study Value**: Reference for larger companies ("If it works for SMEs, it works for us")
✅ **Personal Relationships**: Direct access to decision-maker (vs layers of management)
✅ **Government Grants**: SMEs love 50-70% funding (PSG, EDG)

❌ **Disadvantages** (manageable):
- Smaller contract value (S$30-60K vs S$200K+ enterprise)
- May have less sophisticated IT infrastructure
- Tighter budgets (need to prove ROI quickly)
- Less able to absorb pilot failures

**Strategy**: Start with 2-3 SME pilots → Use as proof points → Scale to enterprise (Ninja Van, DHL)

## Ideal SME Profile

### Target Company Characteristics:

**Size**:
- 10-100 employees (warehouse + delivery)
- 20,000-50,000 packages/month (manageable pilot scale)
- 5,000-20,000 sqft warehouse
- 1-3 sorting lines

**Pain Points**:
- Hiring difficulty (can't compete with large 3PLs on wages)
- High worker turnover (30-50% annually)
- Manual sorting errors (3-8% error rate)

**Technology Readiness**:
- Basic WMS (even Excel-based is okay for pilot)
- CCTV cameras (even basic 720p works)
- Wi-Fi/LAN network
- Willingness to try new technology

**Decision-Maker**:
- Owner/Founder (makes decisions quickly)
- Operations Manager (has budget authority)
- GM/CEO (hands-on, understands operations)

**Financial**:
- Profitable or break-even (not burning cash)
- Growth-focused (expanding, hiring)
- Open to government grants (PSG, EDG)
- Can invest S$10-20K for pilot

## Pilot Structure for SMEs

### Scaled-Down Pilot (30-45 Days)

**Scope** (smaller than enterprise):
- 2-5 cameras (vs 10 for enterprise)
- 1 sorting line (vs 2-3)
- 10-30K packages/month (vs 100K+)
- 2-3 use cases (vs full suite)

**Timeline**: 30-45 days (vs 60 days enterprise)

---

### Phase 1: Setup (Week 1)

**Day 1-2: Site Visit & Assessment**
- Tour warehouse facility
- Identify optimal camera placement (2-5 locations)
- Assess network infrastructure (Wi-Fi, LAN)
- Meet warehouse team (manager + 3-5 workers)
- Document baseline metrics:
  - Current error rate (manual audit)
  - Current sorting speed (packages/worker/hour)
  - Current training time for new hires

**Day 3-5: Installation**
- Install 2-5 cameras at sorting stations
- Set up processing (cloud or local laptop)
- Test connectivity and live feed
- Initial AI training (50-100 package images)

**Day 6-7: Training & Orientation**
- Worker orientation (15-20 minutes)
  - How to read SIMISAI screen
  - Language selection (if multilingual workers)
  - What to do when red alert shows (damage)
- Supervisor training (30 minutes)
  - Dashboard access
  - How to read accuracy reports
  - Troubleshooting basics

**Deliverables**:
- Cameras installed and live
- Baseline report (current performance)
- Team trained and ready

---

### Phase 2: Live Pilot (Week 2-4)

**Week 2: Parallel Operation**
- SIMISAI runs alongside existing process
- Workers still use manual scanners (backup)
- SIMISAI provides guidance, workers can override
- Daily monitoring by SIMISAI team (remote)
- Daily accuracy reports sent to manager

**Week 3: Primary Operation**
- Workers rely on SIMISAI as primary tool
- Manual scanning only for failed detections (<5%)
- Multilingual interface testing (if applicable)
- Fine-tuning AI based on error patterns

**Week 4: Independent Operation**
- SIMISAI operates independently
- Spot-check audits only (vs continuous manual)
- Data collection for ROI analysis
- Worker feedback survey

**Deliverables**:
- Weekly progress reports (emailed every Friday)
- Running accuracy metrics (dashboard access)
- Issue log (any downtime, false positives)

---

### Phase 3: Results & Decision (Week 5-6)

**Week 5: Data Analysis**
- Compare pilot performance to baseline
- Calculate actual cost savings (based on real data)
- Worker satisfaction survey (1-5 scale)
- Manager feedback session (30-min call)

**Week 6: Final Report & Decision**
- Present results (slides + PDF report)
- Financial analysis (ROI spreadsheet)
- Recommendation: Continue to production or not?
- If yes: Implementation plan + pricing proposal

**Deliverables**:
- Final pilot report (10-15 pages)
- ROI calculation (before/after comparison)
- Video testimonial (if willing)
- Case study draft (for marketing)

---

### Pilot Success Criteria (SME-Adjusted)

**Must-Have** (Go/No-Go):
- ✅ **>85% Detection Accuracy** (slightly lower than enterprise target)
- ✅ **>30% Error Reduction** (still significant improvement)
- ✅ **<8% False Positive Rate** (tolerable for SME)
- ✅ **>90% System Uptime** (minimal technical issues)
- ✅ **Positive Worker Feedback** (3.5/5 or higher)

**Nice-to-Have**:
- 🎯 **>50% Error Reduction** (better than target)
- 🎯 **>40% Speed Improvement** (throughput increase)
- 🎯 **Zero Downtime** (perfect technical execution)
- 🎯 **Workers Love It** (4.5/5+ rating)

- [ ] Book site visit (if interested)

- [ ] Tour warehouse facility
- [ ] Meet warehouse manager + key workers

- [ ] Take photos/videos (with permission)
- [ ] Discuss baseline metrics (how to measure current errors)

- [ ] Address concerns/questions

- [ ] Send pilot proposal (PDF, 3-5 pages)

- [ ] Document baseline metrics (current error rate, speed)

**Week 2: Parallel Operation**
- [ ] SIMISAI runs alongside existing process
- [ ] Monitor accuracy daily (remote dashboard)

**Week 3: Primary Operation**
- [ ] Workers rely primarily on SIMISAI
