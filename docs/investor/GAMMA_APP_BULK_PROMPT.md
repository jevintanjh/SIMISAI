- 60% visual content, 30% whitespace, 10% text
- Use Unsplash high-resolution photos (minimum 1920x1080) - NO AI-generated images

- Typography: Sans-serif (Montserrat/Inter), titles 36-48pt, body 18-24pt
- Icons: Consistent modern line-style icons throughout
- Cultural focus: Southeast Asian subjects preferred

## 🎨 ADDITIONAL INSTRUCTIONS FOR GAMMA.APP

**Image Selection Priority:**
1. Always use AUTHENTIC PHOTOGRAPHS from Unsplash/Pexels (NO AI-generated images)
2. Prioritize Southeast Asian subjects (Filipino, Indonesian, Thai, Vietnamese features)
3. If SE Asian limited, use East Asian (Chinese, Japanese, Korean) as alternative
4. Minimum resolution: 1920x1080 (Full HD)
5. Natural lighting, authentic emotions, professional quality

**Visual Design Rules:**
1. Every slide must have 60%+ visual content (images, charts, diagrams)
2. Text limited to 40-50 words maximum per slide
3. Use COLOR-CODED elements (green for positive/SIMISAI, red for negative/problems)
4. Charts must have LARGE labels, minimal gridlines
5. Icons must be consistent style throughout (modern line icons, 48-64px)

**Layout Philosophy:**
1. Visual elements should DOMINATE the slide
2. Text should support visuals, not compete with them
3. Whitespace is essential (30% minimum per slide)
4. Most important visual should be largest element
5. Avoid text-heavy bullet lists - use icons and infographics instead

**Color Consistency:**
- Primary: Teal/Turquoise (#00A896) - use for SIMISAI brand elements, positive indicators, primary data
- Secondary: Navy Blue (#002147) - use for text, supporting elements, authority
- Accent: Warm Orange (#FF6B35) - use for CTAs, growth indicators, energy elements
- Success: Green (#00C851) - use for checkmarks, positive comparisons
- Urgency: Red (#CC0000) - use sparingly for problem statements, negative comparisons

**Typography Standards:**
- All text must be readable from 10 feet away (minimum 18pt)
- Titles: Bold sans-serif, 36-48pt
- Body: Regular sans-serif, 18-24pt
- Labels: 16-18pt
- Consistent font family throughout (Montserrat, Inter, or Poppins preferred)
