## 🚀 Quick Start for Investor Pitch

### **Week 1-2: Preparation**
1. Read `simisai-5min-pitch-deck.md` (familiarize with slides)
2. Create slides on Gamma using [`../automation/gamma-app-slide-prompts.md`](../automation/gamma-app-slide-prompts.md)
3. Practice full pitch 5+ times with timer

### **Week 1-2: Demo Prep**
1. Study `simisai-demo-script.md` (understand demo flow)
2. Test demo 10+ times on actual devices
3. Record backup demo video (3-4 minutes)

### **1 Day Before**
1. Follow checklist in `simisai-15min-presentation-workflow.md`
2. Full dress rehearsal with timer
3. Print materials, charge devices

### **Day Of**
1. Follow "Morning Of" and "On-Site" checklists
2. Arrive 30 minutes early
3. Test venue setup
4. Deliver with confidence!
