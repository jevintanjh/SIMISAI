# SIMISAI Investor Presentation - Gamma.app Slide Prompts

**Purpose**: Individual slide prompts optimized for Gamma.app regeneration
**Format**: Copy-paste each slide prompt into Gamma.app's "Regenerate slide" or "Edit with AI" feature
**Design Philosophy**: Visual-first, 60% images, 30% whitespace, 10% text maximum

---

## 🎨 GLOBAL DESIGN DIRECTIVES

Apply these to ALL slides:

- **Text Limit**: Maximum 40-50 words per slide (strictly enforced)
- **Visual Ratio**: 60% visual content, 30% whitespace, 10% text
- **Image Quality**: Use Unsplash high-resolution photos (minimum 1920x1080)
- **No AI Images**: Use only authentic stock photography from Unsplash/Pexels
- **Color Palette**:
  - Primary: Teal/Turquoise (#00A896) - trust, healthcare
  - Secondary: Navy Blue (#002147) - professionalism
  - Accent: Warm Orange (#FF6B35) - energy, innovation
- **Typography**:
  - Titles: Sans-serif bold (Montserrat/Inter), 36-48pt
  - Body: Sans-serif regular, 18-24pt
  - Minimum readable size: 18pt
- **Icons**: Use consistent icon set throughout (Font Awesome or Heroicons style)
- **Cultural Focus**: Southeast Asian subjects preferred (Filipino, Indonesian, Thai, Vietnamese)
