## 🎯 RECOMMENDED PREPARATION WORKFLOWS

### **Workflow 1: Standard Investor Pitch (15-minute slot)**

#### **Week 1-2: Content Preparation**
1. ✅ Read [`pitch-materials/simisai-5min-pitch-deck.md`](pitch-materials/simisai-5min-pitch-deck.md)
2. ✅ Create slides on Gamma using [`automation/gamma-app-slide-prompts.md`](automation/gamma-app-slide-prompts.md)
3. ✅ Find images using [`image-sourcing/image-sourcing-guide.md`](image-sourcing/image-sourcing-guide.md)
4. ✅ Practice pitch 5+ times with timer

#### **Week 1-2: Demo Preparation**
1. ✅ Read [`pitch-materials/simisai-demo-script.md`](pitch-materials/simisai-demo-script.md)
2. ✅ Test live demo 10+ times
3. ✅ Record backup demo video (3-4 minutes)
4. ✅ Prepare 2 phones + laptop with backup

#### **1 Day Before: Final Prep**
1. ✅ Follow checklist in [`pitch-materials/simisai-15min-presentation-workflow.md`](pitch-materials/simisai-15min-presentation-workflow.md)
2. ✅ Full dress rehearsal with timer (10 minutes target)
3. ✅ Print materials (workflow, demo script, one-pagers)
4. ✅ Charge all devices to 100%

#### **Day Of: Execution**
1. ✅ Follow "Morning Of" and "On-Site" checklists
2. ✅ Arrive 30 minutes early
3. ✅ Test venue setup (Wi-Fi, projector, demo)
4. ✅ Keep demo script in pocket
5. ✅ Deliver with confidence!

## 💡 PRO TIPS

### **Before Presentation**
✅ Sleep 8+ hours the night before
✅ Arrive 30 minutes early (test everything)
✅ Practice deep breathing (calm nerves)
✅ Review opening hook and closing statement

### **During Presentation**
✅ Make eye contact with all judges
✅ Smile and show enthusiasm
✅ Speak clearly with energy (not too fast)
✅ Handle failures gracefully (backup plans exist)
✅ Stay within time limit

### **During Q&A**
✅ Listen to full question before answering
✅ Pause 1-2 seconds before responding
✅ Answer concisely (30-45 seconds max)
✅ If unsure, say: "Great question—I'll follow up with data"
✅ Stay calm and confident

### **After Presentation**
✅ Follow up within 24 hours
✅ Personalize each email
✅ Offer next steps (calendar link)
✅ Track investor responses
✅ Celebrate! 🎉
