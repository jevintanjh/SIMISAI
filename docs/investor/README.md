## 💡 Documentation Philosophy

### **Less is More**
We have lots of documentation, but you don't need to read all of it. Use the navigation guides above to find exactly what you need for your current task.

### **Task-Based Navigation**
Instead of reading files sequentially, start with what you need to DO:
- Pitching? → [Pitch Deck](/docs/investor/SIMISAI-LOGISTICS-PITCH-DECK-2025.md)
- Outreach? → [SME Pilot Guide](/docs/investor/SIMISAI-SME-PILOT-GUIDE.md)
- Discovery call? → [Workflow Improvements](/docs/investor/SIMISAI-LOGISTICS-WORKFLOW-IMPROVEMENTS.md)

### **Avoid Overwhelm**
- **Don't read everything** - It's organized for reference, not linear reading
- **Use the cheat sheet** - [Quick Reference](/docs/investor/LOGISTICS-QUICK-REFERENCE.md) has the essentials
- **Follow action plans** - [Bootstrap GTM](/docs/investor/SIMISAI-BOOTSTRAP-GTM-PLAN.md) tells you exactly what to do
