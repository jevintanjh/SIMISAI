**Claims to Defend:**
- "$50 billion market opportunity" (TAM/SAM/SOM breakdown)
- "18-24 months to replicate our technology" (competitive moat defense)
- "Won Singapore's national AI competition" (validation)
- "Only platform combining CV + AI + multilingual" (differentiation)

- Due diligence phase

## 🔍 How to Use These Documents

**Before Pitch:**
1. Review `claim-justification-summary.md`
2. Memorize key defense points for "$50B market" and "18-24 months"
3. Practice responding to tough questions

**After Pitch:**
1. Note investor questions and objections
2. Update `claim-justification-summary.md` with new evidence
3. Review `presentation-update-guide.md` for improvement ideas

## 💡 Best Practices

### **Claim Justification**
✅ Update after every pitch (note new questions)
✅ Gather supporting data and sources continuously
✅ Practice defending claims conversationally (not just data recitation)
✅ Anticipate skeptical investor mindset
✅ Keep evidence sources bookmarked for quick access

### **Presentation Updates**
✅ Implement changes incrementally (test each change)
✅ Get feedback from multiple audiences
✅ Maintain version control (track what changed and why)
✅ Document lessons learned from each pitch
✅ Balance innovation with proven structure

### **Slide Mapping**
✅ Update mapping after major slide changes
✅ Use for training new presenters
✅ Identify redundant or missing content
✅ Ensure logical narrative flow
✅ Test transitions between slides

### **Version 2 Planning**
✅ Review quarterly (don't over-plan)
✅ Balance ambition with execution capacity
✅ Incorporate real investor feedback (not just internal ideas)
✅ Prioritize changes that address common objections
✅ Keep Version 1.0 stable while planning Version 2.0

## 🚨 Common Use Cases

### **Investor Asked: "How did you calculate the $50B market?"**
→ Use `claim-justification-summary.md` to provide breakdown:
- TAM: Total addressable market calculation
- SAM: Serviceable addressable market
- SOM: Serviceable obtainable market
- Sources: Gartner, Forrester, Statista, etc.

### **Investor Asked: "Why can't Google or Microsoft build this quickly?"**
→ Use `claim-justification-summary.md` to explain:
- Multilingual SEA language expertise (Sealion model)
- Medical device domain knowledge
- Computer vision specialization for device detection
- Integrated platform complexity
- 18-24 month timeline justification

### **Feedback: "Slides are too text-heavy"**
→ Use `presentation-update-guide.md` to:
- Identify visual improvement opportunities
- Implement design best practices
- Balance content with visuals
- Improve readability and impact

### **Planning: "What's next after this pitch deck?"**
→ Use `version-2-executive-summary.md` and `version-2-strategy-and-action-plan.md` to:
- Understand roadmap for Version 2.0
- Prioritize enhancements
- Plan timeline for improvements
- Align team on future direction
