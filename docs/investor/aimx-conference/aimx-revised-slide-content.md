## 🎨 DESIGN SPECIFICATIONS FOR REVISED SLIDES

### Color Palette (Consistent Throughout)

**Primary Colors**:
- **Teal/Turquoise** (#00A896): Brand, positive indicators, SIMISAI elements
- **Navy Blue** (#002147): Text, authority, supporting elements
- **Warm Orange** (#FF6B35): CTAs, energy, growth indicators

**Accent Colors**:
- **Green** (#00C851): Success, validation, checkmarks (✓)
- **Red** (#CC0000): Urgency, problem statements (use sparingly)
- **Gray** (#E0E0E0): Competitors, secondary information

### Typography Standards

**Titles**:
- Font: Sans-serif bold (Montserrat, Inter, Poppins)
- Size: 36-48pt
- Color: Navy Blue (#002147)

**Body Text**:
- Font: Sans-serif regular
- Size: 18-24pt
- Color: Navy Blue or black
- Line height: 1.5x font size

**Labels/Captions**:
- Font: Sans-serif light
- Size: 14-18pt
- Color: Gray or navy

**Text on Images**:
- Always use dark gradient overlay (40-60% opacity) OR drop shadow
- White text on dark backgrounds, dark text on light backgrounds
- Minimum contrast ratio: 4.5:1 (WCAG AA standard)

### Visual Hierarchy

**60-30-10 Rule** (Apply to ALL slides):
- **60% Visual Content**: Images, charts, diagrams, icons
- **30% Whitespace**: Breathing room, negative space
- **10% Text**: Minimal, high-impact text only

**F-Pattern Reading Flow**:
- Top-left: Most important visual element
- Middle-center: Supporting visuals
- Bottom-right: CTA or takeaway

### Icon Specifications

**Size**: 48-64px for primary icons
**Style**: Consistent line-style icons throughout (e.g., Heroicons, Font Awesome)
**Colors**: Teal for primary actions, navy for secondary, orange for CTAs
**Stroke Weight**: Consistent (2-3px)

### Healthcare Track Winner Badge
