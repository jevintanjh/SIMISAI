## QUICK REFERENCE: COMMANDS

### Install SlideSpeak MCP

```bash
# Get API key from https://slidespeak.co/slidespeak-api/

claude mcp add-json "slidespeak" '{
  "command": "npx",
  "args": [
    "mcp-remote",
    "https://mcp.slidespeak.co/mcp",
    "--header",
    "Authorization: Bearer YOUR-API-KEY-HERE"
  ],
  "timeout": 300000
}'

claude mcp list
```
